# Radio Station

A web-based internet radio player built with React, TypeScript, and Tailwind CSS.

## Features

- 8 curated internet radio stations (via SomaFM)
- Live audio streaming with play/pause controls
- Animated visualizer bars while playing
- Volume control with mute toggle
- Beautiful dark UI with per-station color themes
- Ambient background glow that adapts to the active station

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** for bundling
- **Tailwind CSS** for styling
- HTML5 Audio API for streaming

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:5173 and click any station to start listening.
